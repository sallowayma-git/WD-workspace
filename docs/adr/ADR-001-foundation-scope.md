# ADR-001：Foundation 初始化范围

## 状态

Accepted — 2026-08-16

## 决策

第一批实现只建立 SDD 拓扑、严格前端应用框架、Tauri 薄壳入口、统一开发脚本和 PostgreSQL/Flyway 的接口边界。Today、学生、模板、轨道和顺延不在没有 API/数据库真值时用假数据实现。

## 原因

- PRD/SDD 把服务端状态真值、模板/轨道/实例分层和权限审计列为不可弱化的不变量。
- WBS Phase 0 的退出门禁要求干净环境、迁移、模块、RBAC、租户与 CI 证据；静态页面不能替代这些证据。
- 当前仓库为空，且本机尚未安装 Java/Docker；先把缺失依赖显式化，避免把环境问题隐藏在源码中。

## 后果

当前浏览器可构建并显示工程状态；业务路由明确标注未进入相应阶段。API、迁移和桌面构建入口会在后续 Foundation 提交中关闭。
