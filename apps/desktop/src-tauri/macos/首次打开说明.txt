助教工作台 · macOS 首次打开说明
================================

为什么会出现「文件已损坏，无法打开」？
--------------------------------------
本应用没有购买 Apple 开发者账号，所以没有做 Apple 的代码签名与公证。
macOS 会给从网上下载的应用打一个「隔离标记」（com.apple.quarantine）。
「没有签名」+「有隔离标记」两个条件同时成立时，系统就会报：

    助教工作台 已损坏，无法打开。你应该将它移到废纸篓。

这不是文件真的坏了，而是系统的安全策略拦住了它。删掉那个隔离标记就能正常打开。
下面两种方法任选一种，**只需要做一次**。


方法一（推荐，一定有效）：手动执行一次终端命令
----------------------------------------------
1. 把「助教工作台」拖进「应用程序」文件夹（Applications）
2. 打开「终端」：按 Command + 空格，输入 Terminal，回车
3. 复制下面这一整行，粘贴到终端窗口，按回车：

   xattr -dr com.apple.quarantine "/Applications/助教工作台.app"

4. 如果上一步提示没有权限，改成下面这行再试一次（会要求输入开机密码）：

   sudo xattr -dr com.apple.quarantine "/Applications/助教工作台.app"

5. 回到「应用程序」文件夹，双击「助教工作台」，就能打开了


方法二（一键脚本）：双击本磁盘映像里的「修复并打开.command」
------------------------------------------------------------
双击后脚本会自动完成上面的操作，并直接打开应用。

注意：脚本文件本身也会被系统打上隔离标记，所以第一次双击可能提示「来源不明」。
遇到这种情况请：右键点「修复并打开.command」→ 选「打开」→ 在弹出的对话框里
再点一次「打开」。这样就能运行了。

如果脚本仍然无法运行，请直接用「方法一」，那条路不依赖任何脚本。


常见问题
--------
Q：以后每次打开都要这样操作吗？
A：不用。隔离标记删除后就是永久的，之后正常双击即可。

Q：这个操作安全吗？
A：安全。xattr 只是删掉「这个文件来自互联网」的备注，不修改应用本身，
   也不会降低系统的其他安全设置。

Q：为什么不做签名，让我们省掉这一步？
A：Apple 的开发者账号需要每年付费。目前项目没有账号，所以只能这样分发。
   以后如果购买了账号，可以改为正常签名 + 公证，那时这个说明文件就不需要了。

Q：Windows 用户需要做这些吗？
A：不需要。这些只针对 macOS。
